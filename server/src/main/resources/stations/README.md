# Names of the railway stations

`stations.tsv` lists the main railway stations of France, Spain, Italy, Germany, Belgium, the Netherlands, Luxembourg,
Switzerland and Austria, and all the stations of France sold by the SNCF, with their name in French, Spanish, English,
Dutch, German and Italian. It is used to display a station under the same name whatever the feed, and in the language of
the user (`language` argument of the tools). A train stop named only as a station by its feed ("Gare SNCF", "PEM Gare
Routière" of the ZOU ! feed for Sorgues and Orange) takes the name of the station there.

It is generated by `./gradlew :tools:station-names:run` (`tools/station-names/`) from:

- the [Trainline stations](https://github.com/trainline-eu/stations) (UIC code, coordinates, local name), distributed under
  the [Open Database License (ODbL)](https://opendatacommons.org/licenses/odbl/1-0/);
- the labels of the municipalities of [Wikidata](https://www.wikidata.org/) (CC0).

This file is a derived database: it is published under the **ODbL 1.0**, and credits Trainline stations
(© their contributors). Do not edit it by hand: change the generator and run it again.
