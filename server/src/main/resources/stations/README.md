# Names of the railway stations

`stations.tsv` lists the main railway stations of France, Spain, Italy, Germany, Belgium, the Netherlands, Luxembourg,
Switzerland and Austria with their name in French, Spanish, English, Dutch, German and Italian. It is used to display a
station under the same name whatever the feed, and in the language of the user (`language` argument of the tools).

It is generated by `scripts/generate_station_names.py` from:

- the [Trainline stations](https://github.com/trainline-eu/stations) (UIC code, coordinates, local name), distributed under
  the [Open Database License (ODbL)](https://opendatacommons.org/licenses/odbl/1-0/);
- the labels of the municipalities of [Wikidata](https://www.wikidata.org/) (CC0).

This file is a derived database: it is published under the **ODbL 1.0**, and credits Trainline stations
(© their contributors). Do not edit it by hand: change the script and run it again.
